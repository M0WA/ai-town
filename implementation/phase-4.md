## Phase 4: Audio Foundation

### Goal
Deliver the complete `AudioSystem` RAII class with source pool, streaming architecture, 3D spatial audio, occlusion, and HRTF — all according to the spec's mandatory shutdown and thread-safety requirements.

### Deliverables
- [ ] `AudioSystem` RAII class: `alcOpenDevice` + `alcCreateContext` with HRTF attrs; `ALC_HRTF_SOFT=ALC_TRUE`; `alcMakeContextCurrent` before any AL call; `ALC_SOFT_HRTF` presence check; `default.mhr` shipped alongside binary (ref: `architecture/audio-architecture/audio-system.md`, `architecture/audio-architecture/hrtf-initialization.md`)
- [ ] `AudioSystem` destructor is exception-safe for partial construction: use separate nullable boolean flags (`m_deviceCreated`, `m_contextCreated`, `m_contextMadeCurrent`) checked before each cleanup step; each cleanup action is guarded by its corresponding flag so that a constructor that fails mid-sequence (e.g., `alcCreateContext` fails after `alcOpenDevice` succeeds) does not attempt to destroy resources that were never created. Document partial-construction failure paths in `src/audio/audio_system.h` comments. (ref: `architecture/audio-architecture/audio-system.md`, `architecture/audio-architecture/audio-thread-shutdown.md`)
- [ ] `alDistanceModel(AL_INVERSE_DISTANCE_CLAMPED)` called after `alcMakeContextCurrent` succeeds, before any source creation (ref: `architecture/audio-architecture/hrtf-initialization.md`)
- [ ] `ALC_EXT_thread_local_context` extension check + `alcGetProcAddress("alcSetThreadContext")` at `AudioSystem` construction; if extension absent OR function pointer is null: **hard initialization failure only** — audio thread must set `m_initError = true`, signal `m_initCV`, and return without entering the streaming loop; no `alcMakeContextCurrent` fallback on main thread is permitted. **`m_useThreadLocalCtx` shutdown contract**: `m_useThreadLocalCtx = true` when the extension is present and the thread-local context is active; `m_useThreadLocalCtx = false` when absent (hard init failure path). In shutdown Step 3.5: `if (m_context && m_useThreadLocalCtx) { alcMakeContextCurrent(m_context); }` re-binds the context to the main thread AFTER `join()` before any AL cleanup. `m_useThreadLocalCtx` does NOT enable any audio-capable fallback — its only use is Step 3.5 re-binding. **A developer MUST NOT skip Step 3.5 when `m_useThreadLocalCtx = true`** — omitting the re-bind leaves the main thread with no current context and causes undefined behavior on all subsequent AL resource deletion. (ref: `architecture/audio-architecture/streaming-architecture.md`)
- [ ] Audio thread launch after all EFX state, filter objects, and `m_occlusionGainTarget[]` initialization (all `m_occlusionGainTarget` elements initialized to 1.0f before thread launch) (ref: `architecture/audio-architecture/audio-system.md`, `architecture/audio-architecture/audio-occlusion.md`)
- [ ] Audio thread: calls `alcSetThreadContext(m_context)` as first action; signals `m_initCV` (success or error path); enters streaming loop; wakes every 10 ms via `m_streamCV.wait_for` (ref: `architecture/audio-architecture/streaming-architecture.md`)
- [ ] `AudioSystem` constructor waits on `m_initCV` with 5 s timeout (predicate form, lock held via `unique_lock`) before returning (ref: `architecture/audio-architecture/audio-system.md`)
- [ ] Audio thread loop: check `m_stopThread` FIRST after waking before any AL call (ref: `architecture/audio-architecture/streaming-architecture.md`)
- [ ] OGG decode outside `m_streamMutex`; split-lock pattern (acquire mutex briefly for AL queue ops, release, decode, re-acquire) (ref: `architecture/audio-architecture/streaming-architecture.md`)
- [ ] Audio thread shutdown sequence (mandatory order): `m_stopThread.store(true)` → `m_streamCV.notify_all()` → `joinable()` guard then `join()` → **Step 3.5** re-bind context to main thread: `if (m_context && m_useThreadLocalCtx) { alcMakeContextCurrent(m_context); }` — mandatory before any AL cleanup call; omitting this leaves the main thread with no current context, causing undefined behavior on all subsequent AL resource deletion → streaming source stop + query `AL_BUFFERS_QUEUED` + unqueue (never hardcode count) → SFX pool source stop + `alSourcei(AL_BUFFER, 0)` → EFX filter cleanup (loop bound `kEvictableSFXCount=55`, per-filter null check, mid-loop failure cleanup) → `alDeleteSources` + `alDeleteBuffers` → `alcMakeContextCurrent(nullptr)` → `alcDestroyContext` → `alcCloseDevice` (ref: `architecture/audio-architecture/audio-thread-shutdown.md`)
- [ ] Error checking: `alCheckError(op)` for all AL calls; `alcCheckError(device, op)` for all ALC calls; both throw `std::runtime_error` on failure (ref: `architecture/audio-architecture/error-checking.md`)
- [ ] Source pool: 62 pre-allocated AL sources; named constants `kEvictableSFXCount=55`, `kStingerCount=2`, `kSFXPoolSize=58`, `kStreamSourceCount=4`, `kTotalSources=62`; `kTransientReserveStart=51` (V1: stinger sources are indices 55..56 only; sources[57] is reserved evictable post-V1 game-over slot) (ref: `architecture/audio-architecture/source-pool.md`)
- [ ] `AudioSourcePool::acquireSFXSource(SoundPriority)`: LOW/NORMAL consider sources[0..50]; HIGH/CRITICAL consider sources[0..54] (ref: `architecture/audio-architecture/source-pool.md`)
- [ ] `AudioSourcePool::acquireStreamSource()`: returns `AL_NONE` if all 4 in use; ambient beds MUST use stream partition (ref: `architecture/audio-architecture/source-pool.md`)
- [ ] `acquireStingerSource(StingerType)`: V1 enum `CRISIS=55, MILESTONE=56` (GAME_OVER=57 is post-V1 only); V1 stinger sources (indices 55..56) set `AL_SOURCE_RELATIVE=AL_TRUE`, `AL_ROLLOFF_FACTOR=0.f` at pool construction; sources[57] is evictable in V1 (ref: `architecture/audio-architecture/source-pool.md`)
- [ ] `acquireVehicleEnginePair(outIdle, outMove)`: atomic 2-slot acquisition or fail entirely; `releaseVehicleEnginePair(idle, move)` returns both atomically; eviction treats pair as unit (ref: `architecture/audio-architecture/source-pool.md`)
- [ ] EFX occlusion: `ALC_EXT_EFX` check + entry point loading stored as `AudioSystem` members before thread launch; `kEvictableSFXCount` filters only; per-filter null check in allocation loop; **two separate boolean guards required**: `m_efxAllocationAttempted` (set `true` before first `m_fnGenFilters` call; guards destructor cleanup loop to prevent leaking partial allocations) and `m_efxAvailable` (set `true` only after ALL `kEvictableSFXCount` filters fully allocated and configured; guards all runtime occlusion paths); destructor filter cleanup loop uses `m_efxAllocationAttempted` as guard (NOT `m_efxAvailable`) to clean up partial allocations where `m_efxAvailable` was set `false` mid-loop; `AL_LOWPASS_GAIN=0.1f` occluded floor; `AL_LOWPASS_GAINHF=0.3f` on occlusion transition; smoothing step `kOcclusionGainStep=0.05f` per 10 ms wake; dirty-check optimization; `onSourceRecycled()` resets gain state under `m_occlusionMutex`; raycast ≤ 1 per source per 6 frames, ≤ 8 per frame total, only for sources within 100 m; `m_occlusionMutex` declared as `std::mutex` member of `AudioSystem`; `onSourceRecycled(int i)` acquires `m_occlusionMutex` before EFX filter writes; `updateOcclusion()` acquires `m_occlusionMutex` for the section writing to `m_occlusionFilter[]` via EFX calls (not for the entire 10 ms wake cycle) (ref: `architecture/audio-architecture/audio-occlusion.md`, `architecture/audio-architecture/audio-system.md`)
- [ ] 3D spatial audio per-category parameters: rolloff factors, reference/max distances per spec table; listener sync `syncListenerToCamera()` updating `AL_POSITION`, `AL_VELOCITY=0`, `AL_ORIENTATION` (6-float) every frame; vehicle source `AL_VELOCITY=(0,0,0)` (no Doppler) (ref: `architecture/audio-architecture/spatial-audio.md`)
- [ ] Streaming: 8 buffers × 64 KB each; `AudioStream` holds `OggVorbis_File` as a persistent member (opened via `ov_fopen` or `ov_open_callbacks`; closed via `ov_clear` in destructor); `kSamplesPerBuffer = 64*1024/(2*2) = 16384` frames; proactive starvation prevention; starvation recovery resets `m_samplesQueued` and calls `alSourcePlay()` in same lock scope as `alSourceQueueBuffers`; `m_intentionallyStopped` flag set with `alSourceStop` in same `m_streamMutex` lock scope (ref: `architecture/audio-architecture/streaming-architecture.md`)
- [ ] `AL_SOFT_loop_points` check for pre-loaded looping OGG; all pre-loaded OGG buffer ops on audio thread (ref: `architecture/audio-architecture/streaming-architecture.md`)
- [ ] Pre-loaded OGG operations (buffer data upload, `AL_SOFT_loop_points` setup) dispatched via a thread-safe command queue to the audio thread — these operations cannot be called from the main thread when the audio thread holds the thread-local context. Implement a lock-free or mutex-guarded command queue; document the queue mechanism (command type, data fields, enqueue/dequeue contract) in `src/audio/audio_command_queue.h`. (ref: `architecture/audio-architecture/streaming-architecture.md`, `architecture/audio-architecture/audio-system.md`)
- [ ] `AudioSystem` concrete class implementing `IAudioSystem` (interface defined in Phase 1 at `src/interfaces/IAudioSystem.h`); `MockAudioSystem` in `tests/simulation/mock_audio_system.h` (ref: `architecture/testing/testability-architecture.md`)
- [ ] **`IAudioSystem::update()` call site**: `AudioSystem::update()` is called once per frame on the main thread — specifically immediately after `AudioSystem::syncListenerToCamera()` in the render loop's per-frame sequence (after camera position is committed to OpenAL but before `RenderSystem::beginFrame()`). - [ ] `AudioSystem::setGameOverState(bool active)` fully implemented in Phase 4: sets `m_gameOverFade` flag; the audio thread gain-update path checks this flag during stem gain updates and applies the 2-second fade-to-zero when `m_gameOverFade` is true. (ref: `architecture/audio-architecture/dynamic-soundscape.md`)
- [ ] Duck state machine member group includes: `m_gameOverFade` (bool), `m_duckStartGain` (float), `m_duckTimer` (float), `m_musicDuckGain` (float), `m_duckState` (DuckState enum), and `m_lastDuckWakeTime` (double). `m_lastDuckWakeTime` is part of the duck state machine member group — not a separate stub group. **`m_lastDuckWakeTime` MUST be initialized inside the audio thread function, immediately after `alcSetThreadContext(m_context)` succeeds and before entering the streaming loop — NOT in the `AudioSystem` constructor.** Reason: initializing in the constructor causes a large spurious `dt` on the first audio thread wake (the time between constructor completion and first thread wake can be tens of milliseconds or more), which would advance `m_duckTimer` incorrectly on the first iteration. The correct initialization sequence inside the audio thread: `alcSetThreadContext(m_context); m_lastDuckWakeTime = m_clock->nowSeconds(); // then enter loop`. (ref: `architecture/audio-architecture/dynamic-soundscape.md`)

### Exit Criteria
- Audio thread initializes and shuts down cleanly with no AL errors on Linux and Windows
- 3D spatial audio attenuates correctly at configured distances under xvfb/null-audio
- Streaming music plays and loops without starvation for a 5-minute run
- EFX occlusion applies correct gain smoothing (verified by unit test with `ManualClock`)
- DLL verification step passes on Windows CI
- Unit test `AudioThread_AbsentThreadLocalContext_ConstructorThrows`: using a mock `alcIsExtensionPresent` returning `ALC_FALSE`, verifies the constructor throws `std::runtime_error` without entering the streaming loop; labelled `unit`, runs in CI without a real audio device

# Minimum Viable Simulation (V1 Scope)

- **Max agent count**: 10,000 vehicle agents at 60 FPS on mid-range desktop hardware
- **V1 systems**: economy, traffic, population growth, zoning, basic service coverage (fire, police, power, water)
- **Post-V1 systems**: education, health, environment, disasters
- **Map dimensions**: 256×256 tiles minimum; 1024×1024 tiles maximum

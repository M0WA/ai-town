### Exit Criteria

- Economy, traffic, and zoning simulations run for 60 budget ticks without crash
- All unit and property-based tests pass with 80%+ coverage gate green on `coverage-linux`
- Loan mechanics fire at the correct deficit thresholds and respect the 120 s real-time gate AND the first-non-zero-revenue gate (both gates must clear before any forced loan fires)
- City Rating transitions fire correctly at the defined population thresholds; `CityRating_100KPopulation_NoRatingTransition_NoStingerFlag` confirms 100K is not a tier transition
- Traffic demand coupling produces visible zone-growth/decay feedback in manual play-testing
- `ICitySimulation` completeness gate: all 15 new Phase 6 methods (`getSimulationTime`, `pollPendingNotification`, `setTaxRate`, `getTaxRate`, `getTaxRevenue`, `getWagesCost`, `getRoadMaintenanceCost`, `getServiceUpkeepCost`, `getUtilityFeeRevenue`, `placeZone`, `placeRoad`, `demolishTile`, `undoLastAction`, `queryTile`, `getOutstandingBondUses`) compile without error in `MockCitySimulation` (all 15 `MOCK_METHOD` entries present in `tests/ui/mock_city_simulation.h`)
- Undo expiry timestamp: `UndoSystem_ExpiryTime_ComputedCorrectly_AtHighSpeed` passes — `getUndoExpiryTimeSeconds()` returns the correct wall-clock value per the documented formula
- Service coverage N/A sentinel: `PowerCoverage_ZeroTilesInRange_ReturnsNASentinel` passes — zero buildable tiles in range returns `ServiceCoverage::power == -1.0f` (not 100%)
- Population growth/decay caps enforced per `population_growth_cap_fraction` / `population_decay_cap_fraction` constants; rounding via `static_cast<int>(std::round(...))` verified by property test
